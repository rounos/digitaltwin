EchoMind — Digital Twin Engine

1. Περιγραφή της Ιδέας (Concept)

Το EchoMind είναι μια εφαρμογή δημιουργίας Ψηφιακού Διδύμου (Digital Twin) που αναλύει το ψηφιακό αποτύπωμα ενός χρήστη, όπως συνομιλίες, emails, προσωπικές σημειώσεις και έγγραφα, με στόχο να αναπαράγει τον τρόπο σκέψης, το ύφος γραφής και τη λήψη αποφάσεών του.

Χρησιμοποιώντας συνδυασμό ανάκτησης μνήμης (RAG) και μοντελοποίησης προσωπικότητας (Persona Extraction & Stylometry), το σύστημα μπορεί να απαντά σε νέα, άγνωστα ερωτήματα και διλήμματα υιοθετώντας τη φωνή, τις αξίες και τη λογική του πραγματικού χρήστη, βασιζόμενο αποκλειστικά στα δεδομένα του ψηφιακού του αποτυπώματος.

2. Οδηγίες Εγκατάστασης & Εκτέλεσης (Setup & Run)

Docker και Docker Compose εγκατεστημένα στο σύστημά σας.

Έγκυρο OpenAI API key για το προεπιλεγμένο `gpt-6-luna` (χωρίς κλειδί εκκινεί μόνο το offline demo).

3. Κύρια Χαρακτηριστικά & Αρχιτεκτονική

Κύρια Χαρακτηριστικά

Footprint Ingestion & PII Scrubbing: Αυτόματη ανάγνωση πολλαπλών τύπων αρχείων (chats, emails, notes, documents), τεμαχισμός κειμένου (chunking) και ανωνυμοποίηση ευαίσθητων προσωπικών δεδομένων (PII).

Hybrid RAG Memory: Συνδυασμός λεξικής αναζήτησης (BM25) και σημασιολογικής αναζήτησης (Dense Vector Embeddings) για την ανάκτηση των πιο σχετικών αναμνήσεων και εμπειριών του χρήστη.

Persona & Stylometry Modeling: Εξαγωγή βασικών αξιών, προτιμήσεων και στυλομετρικών χαρακτηριστικών (μήκος προτάσεων, λεξιλόγιο, τόνος) για τη διατήρηση της αυθεντικής «φωνής» του χρήστη.

Αξιολόγηση σε Άγνωστα Σενάρια (Unseen Scenarios): Μηχανισμός ελέγχου (evaluation) που μετρά κατά πόσο το twin γενικεύει σωστά σε νέες καταστάσεις χωρίς διαρροή δεδομένων (zero data leakage).

Αρχιτεκτονική (FTI Pattern)

Το σύστημα είναι δομημένο πάνω στο αρχιτεκτονικό πρότυπο FTI (Feature, Training, Inference) με διαχωρισμό σε FastAPI backend και React (Vite) frontend:

Feature Pipeline (ingestion/ & memory/): Επεξεργάζεται τα ακατέργαστα δεδομένα του footprint, αφαιρεί τα PII και αποθηκεύει τα chunks και τα embeddings στη βάση μνήμης (memories.json).

Training Pipeline (persona/): Αναλύει το footprint μέσω LLM και στυλομετρικών κανόνων, παράγοντας ένα δομημένο προφίλ προσωπικότητας (persona_v001.json).

Inference Pipeline (ai/ & api/): Κατά τη συνομιλία, ανακτά τις σχετικές μνήμες μέσω του hybrid retriever, τις συνδυάζει με το προφίλ προσωπικότητας στο system prompt και παράγει την τελική απάντηση.
